# Smart Money Lab — website mockup

A redesign mockup for [Smart Money Lab](https://smartmoneylab.info/), a student-founded nonprofit teaching free financial literacy, leadership and scam-safety workshops.

Plain HTML, CSS and JavaScript. Open `index.html`, or view it live on GitHub Pages.

- `index.html` — home page
- `workshop.html` — sign up for a free online workshop
- `volunteer.html` — volunteer application

Note: the two forms send real responses to Smart Money Lab's Google Forms.
